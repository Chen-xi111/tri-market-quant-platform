# A 股短周期策略实验室

本平台位于独立 Git 分支 `feature/a-share-strategy-lab`，不会修改或占用原 A 股
平台。它复用原平台的 A 股行情读取和代码规范，但策略、回测、缓存、页面入口与
启动端口全部独立。

## 策略口径

- 隔日波段：收盘确认信号，下一交易日开盘尝试成交，最长持有 5 个交易日。
- 当日决策：用于卖出昨日可卖持仓，或今天买入后隔夜持有；不模拟违规的日内回转。
- 买点由趋势、回调/突破、动量、量价与波动质量五类因子组成。
- 卖点包含计划止损、两档止盈、趋势减仓和最长持有期退出。
- 时间外胜率来自最后 35% 的历史窗口，同时展示 95% Wilson 区间和样本量。

## 启动

在本 worktree 根目录执行：

```bash
./run_cn_lab.sh
```

默认地址为 <http://localhost:8504>。如端口被占用：

```bash
./run_cn_lab.sh 8514
```

该平台仅用于研究和模拟，不连接券商，不会自动下单。

## 规则基线

- 股票买入后交收前不得卖出；平台按股票 T+1 处理：
  [上海证券交易所交易规则（2026年修订）](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)
- 创业板普通股票涨跌幅按 20% 建模：
  [深圳证券交易所创业板交易特别规定](https://www.szse.cn/lawrules/rule/repeal/rules/P020231230545310237980.pdf)
- 卖出印花税按 2023 年减半后的 0.05% 假设建模：
  [财政部、税务总局公告 2023 年第 39 号](https://www.mof.gov.cn/jrttts/202308/t20230828_3904235.htm)

佣金、最低佣金、ST/退市整理、新股首日、停牌和真实排队成交可能与模型不同，
页面会把这些列为未覆盖限制。
